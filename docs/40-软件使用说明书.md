## 1. 系统概述

本系统是一个基于协同过滤（UserCF + ItemCF 混合）的 B/S 架构智能推荐网络商城，采用前后端分离模式，提供消费者购物、商家经营、管理员运营三类角色的完整业务闭环。

- 前端：Vue3 + ElementPlus（浏览器访问）
- 后端：Spring Boot 提供 RESTful API
- 数据：MySQL（业务数据）+ Redis（热点/推荐缓存）

## 3. 系统配置

### 3.1 数据库说明

系统共 30 张业务表（含核心 6 表：用户 user、商品 product、订单 orders、用户行为 user_behavior、用户评分 user_score、推荐结果 recommend_result）。

> **说明**：订单表名为 `orders`（复数），为 `order` 的复数形式以规避 SQL 保留字风险，功能语义与任务书"订单表（order）"一致。

### 3.2 后端配置项

| 配置 | 说明 | 默认值 |
|---|---|---|
| `DB_PASSWORD` | MySQL root 密码 | 123456（本地） |
| `REDIS_PASSWORD` | Redis 密码（无则空） | 空 |
| `JWT_SECRET` | JWT 签名密钥（生产必填） | dev 环境有开发默认值 |
| `--server.port` | 后端端口 | 8080 |
| `--spring.profiles.active` | 环境 profile | dev |

### 3.3 端口说明

| 端口 | 服务 |
|---|---|
| 8080 | 后端 API（Knife4j 文档 http://localhost:8080/doc.html） |
| 4173 | 前端页面 |

## 4. 安装与启动

### 4.1 初始化数据库（首次或重置）

```bash
DB_PASSWORD=你的MySQL密码 ./scripts/start-local.sh --reset
# 或仅重置数据库：
MYSQL_ROOT_PASSWORD=你的密码 ./scripts/reset-demo.sh --local
```

该命令重建 `mall` 库并导入全部表结构与演示数据（管理员/测试账号、分类、促销、积分商品、物流公司）。

### 4.2 一键启动

```bash
./scripts/start-local.sh          # 启动后端(8080) + 前端(4173)
./scripts/start-local.sh --stop   # 停止
```

### 4.3 访问

浏览器打开 **http://localhost:4173** 即可进入系统。

## 7. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 后端启动报数据库连接失败 | 检查 MySQL 已启动；`DB_PASSWORD=你的密码` 重新执行 start-local.sh --reset |
| 8080 端口被占用 | 先 `./scripts/start-local.sh --stop`，或排查残留 java 进程 |
| 商品列表为空 | 演示种子数据不含商品，由商家在商家端发布 |
| 登录提示密码错误 | 确认账号来源：admin/Admin@2026（V1 创建）、testuser/Mall@2026（init-data） |
| 忘记管理员密码 | 重置数据库（reset-demo.sh --local）恢复初始账号 |
| 前端页面打不开 | 确认 start-local.sh 已启动且 4173 可访问 |
| 图片上传后不显示 | 前端已代理 /uploads → 后端，检查 8080 是否可达 |

## 8. 数据维护建议

- **日常备份**：`mysqldump -uroot -p mall > mall_backup.sql`
- **演示前重置**：`./scripts/start-local.sh --reset`（一键恢复到干净演示状态）
- **推荐结果更新**：每日定时任务自动全量（02:00）+ 增量（02:30）重算；也可手动调用管理端推荐刷新接口
