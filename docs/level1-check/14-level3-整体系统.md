## 2. 全局异常处理（✅ 质量好）

GlobalExceptionHandler 覆盖：BusinessException / MethodArgumentNotValidException（聚合所有字段错误）/ BindException / HttpMessageNotReadable / MissingParameter / MethodNotSupported / RuntimeException 兜底（500 统一为 SYSTEM_BUSY）。✅ 无遗漏面。
- ⚠️ 例外：部分未捕获异常路径（U-01 updateProfile DuplicateKeyException → 兜底 10005，错误信息不友好，P2）
