# 用户操作手册

> **版本状态**：v0.1.1 规划版，基于毕业设计任务书编制，尚未与实际代码/审计结果核对，详见 `00-文档说明.md`。**以下部署步骤、界面描述均为规划内容**，实际操作以最终交付版本为准；界面截图待系统开发完成后补充。

## 1. 概述

本手册面向系统的三类最终用户——消费者、商家、管理员，介绍系统的运行环境要求、登录方式与各角色的操作指南。

## 2. 运行环境要求

### 2.1 服务器端（部署环境）

| 项目 | 要求 |
|---|---|
| 操作系统 | Linux（推荐 CentOS/Ubuntu）或 Windows Server |
| Java 运行环境 | JDK 11（确定版本号见 `14-项目脚手架与环境规范.md` §1） |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis 6.x/7.x |
| Web服务器（可选） | Nginx（用于反向代理与前端静态资源托管） |
| 内存/CPU建议 | 2核4G及以上（演示环境），生产环境按并发量另行评估 |

### 2.2 客户端（使用环境）

| 项目 | 要求 |
|---|---|
| 设备 | PC 或平板/手机（响应式适配） |
| 浏览器 | Chrome / Edge / Firefox 最新版本（建议使用 Chromium 内核浏览器以获得最佳兼容性） |
| 网络 | 可访问部署服务器的公网/内网地址 |

## 3. 部署说明（规划步骤）

> 以下为规划中的部署步骤，实际部署文档应在系统开发完成后单独编写并附带真实的配置示例。

1. 准备服务器环境：安装 JDK、MySQL、Redis；
2. 导入数据库脚本，创建业务数据库与初始化数据（如管理员账号、商品分类初始数据）；
3. 配置后端应用的数据库连接、Redis 连接等参数；
4. 构建并启动后端 Spring Boot 应用；
5. 构建前端 Vue3 项目（`npm run build`），将构建产物部署至 Nginx 静态资源目录；
6. 配置 Nginx 反向代理，将 `/api` 等接口请求转发至后端应用；
7. 访问前端地址，使用初始管理员账号登录，验证系统可正常访问。

## 4. 登录与角色说明

系统支持三种角色登录：**消费者**、**商家**、**管理员**。登录时系统根据账号角色自动跳转至对应端的功能界面。忘记密码等账号找回机制以实际实现为准。

## 5. 消费者操作指南

### 5.1 浏览与搜索商品

- 首页可按分类浏览商品，支持分页查看商品列表；
- 顶部搜索框输入关键词进行搜索，可结合分类、价格区间进行筛选，并按销量或价格排序；
- 商品详情页支持多图轮播查看，若商品有多种规格（如颜色、尺码），可在详情页选择具体规格。

### 5.2 查看个性化推荐

- 首页"猜你喜欢"板块展示系统基于您的历史浏览、收藏、购买行为计算出的个性化推荐商品；
- 商品详情页"相似商品推荐"板块展示与当前商品相似的其他商品；
- 行为数据积累越多，推荐结果越贴合个人偏好；新用户在积累行为数据前会看到热门商品推荐。

### 5.3 购物车与下单

1. 在商品详情页点击"加入购物车"，可在购物车页面修改数量、删除商品、全选/反选商品；
2. 购物车页面会显示已选商品的合计金额，并对库存不足的商品给出提示；
3. 点击"结算"进入订单确认页，选择收货地址，确认商品与金额信息（含系统按商家运费模板自动计算的运费，满足包邮门槛时运费显示为0）；
4. 选择支付方式（余额支付或模拟支付宝）完成支付，系统生成订单。

### 5.4 订单管理

- 在"我的订单"中可按状态（待付款/待发货/已发货/已收货/已完成）筛选查看订单；
- 支持查看订单详情、取消未支付订单、确认收货、删除已完成或已取消的订单；
- 收到商品后可对商品进行评价。

### 5.5 用户中心

- 管理个人信息（昵称、头像、联系方式）；
- 管理收货地址（新增、编辑、设置默认地址）；
- 查看收藏夹与浏览历史记录。

## 6. 商家操作指南

### 6.1 店铺管理

- 维护店铺基本信息（名称、Logo、简介等），进行店铺页面装修；
- 配置运费模板（按区域设置运费规则，可设置满额包邮门槛），用于消费者下单时自动计算运费。

### 6.2 商品管理

- 通过富文本编辑器发布新商品，填写商品名称、价格、库存、规格、详情描述及图片；
- 对已发布商品进行编辑、上架/下架操作；
- 支持批量操作（如批量上下架、批量调整库存）。

### 6.3 订单与售后管理

- 查看归属本店铺的订单列表与详情；
- 对已付款订单填写物流公司与物流单号完成发货；
- 处理消费者提交的退款/退货申请，审核通过或拒绝。

### 6.4 数据统计

- 查看销售总额、订单数量统计；
- 查看热销商品 TOP10 榜单；
- 查看日/周/月销售趋势图表，辅助经营决策。

## 7. 管理员操作指南

### 7.1 用户管理

- 查看用户列表与详情，对违规用户进行禁用/启用操作，进行角色分配。

### 7.2 商品管理

- 对商家提交的待上架商品进行审核（通过/拒绝）；
- 维护商品分类体系；
- 对已上架但违规的商品进行下架处理。

### 7.3 商家管理

- 审核商家入驻申请；
- 维护商家信息，管理商家等级。

### 7.4 数据看板

- 查看平台整体 GMV 统计、用户增长趋势、订单转化率；
- 查看推荐算法效果分析（如点击率、转化率等指标），评估个性化推荐对经营指标的贡献。

### 7.5 系统管理

- 配置系统参数；
- 查看操作日志，追溯敏感操作（如用户禁用、商品下架、商家审核等）的执行记录；
- 维护数据字典（如商品分类、物流公司等基础数据项）。

## 8. 常见问题（FAQ）

| 问题 | 说明 |
|---|---|
| 为什么"猜你喜欢"里没有个性化内容，全是热门商品？ | 新用户或历史行为数据较少时，系统采用热门商品兜底策略；多浏览、收藏、购买后推荐会逐渐个性化。 |
| 下单时提示"库存不足"怎么办？ | 说明该商品/规格库存已被扣减完毕（可能是并发抢购场景），请等待商家补货或选择其他规格/商品。 |
| 订单一直显示"待付款"，可以取消吗？ | 可在订单详情中手动取消；若超过系统设定的支付时限（如30分钟）未支付，系统会自动取消订单并释放库存。 |
| 物流信息查询不到怎么办？ | 可能是第三方物流查询接口暂时不可用，请稍后重试；如长时间无法查询，请联系商家核实物流单号。 |
| 忘记密码怎么办？ | 以实际系统提供的找回密码/联系管理员重置等机制为准（详细流程待开发完成后补充）。 |
