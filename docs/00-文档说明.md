# 文档说明

## 1. 文档集概述

本目录（`docs/`）汇总了"基于协同过滤算法的智能推荐网络商城的设计与实现"项目的标准软件工程文档，编制依据参考 GB/T 8567《计算机软件文档编制规范》所定义的常见文档集，并结合项目实际（本科毕业设计）进行了适当裁剪与合并，覆盖任务书中"问题定义、可行性研究、需求分析、概要设计、详细设计、测试、软件功能说明"的全部要求。

## 4. 版本状态声明（重要）

> **当前版本：v0.7（规划版，完整性修复通过后的文档集）**
>
> 编写时，本仓库（`online-shopping-mall`）**尚未包含任何源代码，也未开展任何代码安全审计**。因此本文档集属于"设计蓝图"性质：
>
> - 需求、架构、数据库结构、算法设计、接口设计均为**待实现的设计方案**，不是对既有代码的描述；
> - `06-测试计划.md` 中的"审计发现记录表"为**空表模板**，尚无真实审计数据；
> - 待系统开发完成、通过代码审计后，需按照第 5 节的流程对本文档集做一次"一致性回检"，将文档更新为与实际代码、真实审计结论一致的 **v1.0 正式版**。
>
> 在 v1.0 发布之前，请勿将本文档集中的具体接口路径、字段名、类名等实现细节视为最终交付物的确定实现，应以最终代码为准。

## 5. 后续更新流程（代码与审计报告就绪后）

1. 提供源代码仓库路径（前端 + 后端）与数据库迁移脚本；
2. 提供最新的代码审计报告（人工审计意见或工具扫描结果，如 SonarQube/依赖扫描/渗透测试报告）；
3. 逐文档比对：
   - `03-软件需求规格说明书.md`：核对功能需求是否均已实现，标注偏差；
   - `05-详细设计说明书.md`：核对数据库表结构、接口清单、算法实现与代码一致；
   - `06-测试计划.md`：将审计发现填入"审计发现记录表"，补充实际测试结果形成《测试报告》；
4. 在下表登记版本变更，发布 v1.0。
