## 1. 项目概况

- **项目名称**：基于协同过滤算法的智能推荐网络商城（本科毕业设计，攀枝花学院）
- **一句话描述**：三端（消费者 / 商家 / 管理员）完整业务闭环的 B2C 商城，核心亮点为 UserCF + ItemCF 混合推荐算法、跨店铺智能拆单、全链路行为埋点。
- **当前状态**：✅ v1.0 已发布（2026-07-07），历经 v1.1 / v1.2 多轮迭代，当前为 v1.2.1（2026-08-18）；代码实现、测试体系、交付终审全部完成，**可提交答辩**。
- **线上地址**：http://8.160.181.12 （测试阶段部署，无 Docker，直接文件部署；运维细节见 `docs/47`）
- **任务书**：仓库根目录 `项目计划书1-AI智能推荐网络商城.md`（毕业设计任务书，一切需求的源头）

- 测试体系四层建成（详见 §6）；
- **生产缺陷 1 — 雪花 ID 精度**：后端 19 位雪花 Long 超出 JS `Number.MAX_SAFE_INTEGER`（2^53），浏览器 `JSON.parse` 丢精度导致按 ID 操作 404。修复：`safeJson.js` 的 `parseApiJsonSafe` 统一保护（axios transformResponse）+ `Detail.vue` 对 ID 做 `String()`；
- **生产缺陷 2 — 商家商品列表 ErrorBoundary 崩溃**：`List.vue` 的 `getFirstImage` 对空图片数据未做安全解析导致崩溃。修复：安全解析 + 兜底图。
