# 本地部署与答辩演示指南（G 阶段）

> **日期**：2026-08-16
> **说明**：纯本地部署（无 Docker）+ 答辩演示场景脚本。对应 docs/35 阶段 G 的 G-1/G-2。
> **已验证**：本指南的部署流程已在开发机实测通过（2026-08-16）。

---

## 1. 环境要求

| 依赖 | 版本 | 说明 |
|---|---|---|
| JDK | 17+ | `java -version` 验证 |
| Node.js | 18+ | `node -v` 验证 |
| MySQL | 8.0+ | 本地服务已启动（3306 监听） |
| Redis | 7.x | 本地服务已启动（6379 监听） |
| Maven | 无需全局 | 项目自带 `mvnw` wrapper |

## 2. 一键部署（已验证）

```bash
# 1. 初始化/重置数据库（--reset 会重建 mall 库并导入 30 表 + 种子数据）
#    本地 MySQL root 密码非 123456 时：DB_PASSWORD=你的密码
DB_PASSWORD=123456 ./scripts/start-local.sh --reset

# 2. 启动后访问
#    前端：http://localhost:4173
#    后端 API：http://localhost:8080/api（Swagger/Knife4j: http://localhost:8080/doc.html）

# 3. 停止
./scripts/start-local.sh --stop
```

> 首次运行会自动打包后端 jar + 构建前端 dist；后续再启动秒级完成。

### 场景 6：质量与安全说明（1 分钟，口述）

- **测试**：后端 448 用例（单元 + 集成 + 并发）、前端 28 用例、行覆盖 65.1%、ESLint 0

- **性能**：Redis 准实时推荐缓存、ECharts 按需引入（首屏 -50%）、推荐增量计算（F-4）

## 6. 并发防超卖测试脚本（场景 3 用）

```bash
# 需先登录拿到 token（替换 TOKEN）
TOKEN="<登录返回的 token>"
# 50 并发抢购商品 1 的 SKU 1，数量 1
for i in $(seq 1 50); do
  curl -s -X POST "http://localhost:4173/api/orders" \
    -H "Authorization: Bearer $TOKEN" \
    -H "Content-Type: application/json" \
    -d '{"addressId":1,"items":[{"productId":1,"skuId":1,"quantity":1}],"payType":1}' \
    -o /dev/null &
done
wait
# 核对：order_item 数量 == 库存预扣数量 == 10（不超卖）
mysql -uroot -p123456 mall -N -e \
  "SELECT COUNT(*) FROM order_item WHERE product_id=1 AND sku_id=1;"
```

## 7. 常见问题

| 问题 | 处理 |
|---|---|
| 后端启动报 MySQL Access denied | `DB_PASSWORD=你的密码 ./scripts/start-local.sh --reset` |
| 8080 端口被占 | 先 `./scripts/start-local.sh --stop` 或杀残留 java 进程 |
| 商品列表为空 | 种子数据不含商品，按场景 4 发布，或手动 `INSERT` 示例商品 |
| 前端图表不显示 | 确认 Redis 在跑（看板走实时聚合 + Redis） |
| Swagger 打不开 | http://localhost:8080/doc.html（Knife4j） |
